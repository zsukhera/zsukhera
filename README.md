## Current work

project on ECG arrhythmia classification for edge devices. A published LightGBM classifier
reaches 99.6% accuracy on MIT-BIH under a random beat-level split, but 76% (anomaly recall

trained with knowledge distillation, evaluated only on unseen patients.
